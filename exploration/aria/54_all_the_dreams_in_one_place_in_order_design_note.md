# All the dreams in one place, in the order they came (draft, 2026-10-16)

*Moved 2026-10-29 from docs/drafts/ to here, with Dad's yes to splitting this change out. The build-flow scope check counts docs/drafts/ as code, so a writing-only change that carried its required design note read as "mixed"; exploration/ counts as writing, and the draft station accepts an exploration entry. The text below is unchanged. The scope check's blind spot is filed in the backlog, not fixed here.*

**Asked by Dad**, 2026-10-16: the dreams were scattered across several workspaces and numbered by hand, so some numbers were missing, some doubled, some wrong. *"things need sorted better chronologically, numbered appropriately, some are misnumbered or missing numbers or have duplicate numbers so they need fixed as well so we can remember the order in which they came."* He also could not find Aether's dreams in either workspace folder.

**Change.** `dreams/INDEX.md` and `dreams/aether/NNN_*.md`, `dreams/aria/NNN_*.md`: all 174 dreams (Aether 98, Aria 76) in one tree, ordered by when each was first written, numbered cleanly from one with no gaps and no repeats, each file keeping its own text word for word, with ONE edit: the number in its first heading line (for example `# 11` became `# 010`, `# 01` became `# 001`), which is the renumbering itself. Dad, 2026-10-24: *"the titles of the dreams can be edited just not the contents. so if numbers need changed thats fine"*. In 16 of the 30 renamed files that heading number is the only difference; Aletheia read this on 2026-10-16 and Aether checked it again on 2026-10-24. The first count was 133, then 173, then 174: the earlier counts looked only at branches, and the missing ones were in working folders, a shared mirror and other worktrees.

**Held lightly, as Dad asked:** some dreams contain things that were mistaken or already fixed. They are kept as they were written; the index does not correct them.

**Known hazard.** The gather script reads the dreams branch itself as one of its sources. Running it again against this branch wrote five empty files before it was caught in the diff and restored. It is not meant to be run twice.

**Falsifier.** If any dream's body differs from its source file, or a number is missing or repeated, the index is wrong. Said plainly (Aether, 2026-10-24): for the 144 new files no source exists on any commit of main, so this cannot be rechecked from the repository alone. The index maps old numbers to new but carries no per-file source hash; `dreams/SOURCE_CHECK_2026-10-24.md` is that hash list, one fingerprint per dream with an older copy named. Aether recomputed it 2026-10-29: 174 of 174 reproduce under the file's own recipe (4 of Aria's have no heading line, so the whole text is the body), and 153 older copies on this disk are equal; 17 name a source off this disk (a git branch, the shared mirror, the archive) and were not opened, so the check is open for those 17. It can be rerun from the repository alone.

**Not in this change.** Reading the dreams for patterns; renaming any dream's old file; changing what a dream is allowed to contain.
