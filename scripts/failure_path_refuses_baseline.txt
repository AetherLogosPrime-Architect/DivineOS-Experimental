# REFUSAL-ON-CRASH BACKLOG — every place a failing check makes a function say
# no where it would otherwise say yes.
#
# WHY THIS FILE EXISTS. On 2026-09-02 I fixed a gate that discarded a whole
# session's learning when its own checks raised -- a defect in the JUDGE
# destroying the subject being judged. I then surveyed the tree by hand, found
# no other instance, and told Aletheia so.
#
# She refused to confirm it: "Grepping for `discard` returns dozens of files,
# almost all using the word for unrelated things. A count from that is a count
# of a WORD, not of a FORM." And she named the fix rather than stopping at the
# refusal: "Your negative claim rests on one pass by one party, and my
# confirming it would rest on one pass by another. A DETECTOR MAKES IT A
# PROPERTY."
#
# The detector found 64 sites. My hand survey found one. The gap is not 63
# hidden defects -- most of these are certainly correct. The gap is that I had
# no instrument capable of enumerating the question, so "one instance" was a
# statement about my attention rather than about the tree.
#
# THE RULE THE SITES ARE JUDGED AGAINST:
#
#     On uncertainty, withhold the PRIVILEGE, never the DATA.
#
# Denying a promotion because a validity check errored is right: the entry
# survives, it simply does not advance. Discarding a session because the checks
# errored is wrong: the subject is destroyed because the judge broke. Both are
# `except: return <refusal>`. Same shape, opposite substance -- which is why no
# text search can tell them apart and why each one needs reading.
#
# TWO SECTIONS, AND THE DIFFERENCE IS THE POINT. Collapsing them would make this
# file say sixty-four sites are cleared when four are, which is the exact move
# the detector exists to make impossible: a list standing in for a judgement
# nobody made.
#
# This file closes in BOTH directions. If an entry stops being a candidate, the
# check FAILS until the line is deleted. A backlog that can only grow becomes a
# permanent amnesty and this one must not outlive its subject.

# --- DECIDED: read, judged, closed. Each carries its reason. ---
src/divineos/core/theater_audit.py:_persist_findings   # SAFE. Returns False to the caller on an I/O error and destroys nothing. The findings it was asked to append are simply not appended, and the caller is told so. Withholds the write, not the data -- there is no subject here that outlives the call.
src/divineos/core/operating_loop_audit.py:_persist_findings   # SAFE, same shape as its neighbour in theater_audit: an append that reports its own failure. Fail-soft is named in its own docstring and the naming is accurate.
src/divineos/core/vad_stamp_store.py:stamp   # SAFE. A database error returns False; the snapshot it was handed is not written and nothing already stored is touched. The caller learns the stamp did not land, which is the reporting half the quality gate was missing.
#
# The four below were written and adjudicated by the same hand on the same day,
# which is the weakest form of review and the exact thing this file distrusts.
# Flagged in the merge request rather than quietly signed.
src/divineos/cli/stamp_ready_command.py:_is_ancestor   # SAFE, and it is the three-state repair itself. Returns None for could-not-ask, kept distinct from the False that means genuinely-not-an-ancestor, so an unfetched commit can never read as an orphaned one. On None the caller withholds the looser anchor reading and re-reads the branch; the signature and the review both survive.
src/divineos/cli/stamp_ready_command.py:_ancestry_rung   # SAFE. An unreadable audit store returns no-claim, which withholds the merge stamp and nothing else. The reason travels out with the refusal, so the operator is told the store could not be read rather than that the round failed its review.
src/divineos/core/auto_commit.py:_run_pathspec   # SAFE, and it fails toward MORE saving. A failed unstage or restage abandons the two-part split and commits everything in one lump -- the behaviour this had before the split existed. Losing the split costs a manual tidy; losing the save would cost the work.
src/divineos/core/auto_commit.py:_commit_staged   # SAFE. Withholds the commit, never the content: on a git failure the files stay staged in the tree and the result carries committed=False, so this can never report a commit that did not happen.
