# REFUSING GATES WHOSE REFUSAL SITS BEHIND A LOAD THAT FAILS OPEN
#
# Each of these can refuse a tool call, and each loads something first with
# `|| exit 0` -- exit 0 being ALLOW. If that load fails, the gate permits what
# it exists to stop, silently, with nothing saying the check did not run.
#
# FOUND BY ALETHEIA, 2026-09-21, auditing a branch of Aria's and looking past
# the branch at the house. She measured the emergency stop first, which is the
# worst case and is why this got built tonight rather than filed: if the shared
# shell library will not load, the off-switch allows everything.
#
# THE STOP IS REPAIRED AND IS NOT ON THIS LIST. Its load-bearing check now runs
# above every fail-soft load, reading the mode file with plain shell -- possible
# because that file is plain text by deliberate design, so corrigibility works
# when the rest of the system does not. That is the shape a repair takes here.
#
# WHY THE REST ARE PINNED RATHER THAN SWEPT. They need reading one at a time.
# Some genuinely cannot run their check without the library, and for those
# failing closed would wall off the edit that repairs the library -- the
# off-switch-traps-itself failure the corrigibility module rejects by name. A
# blanket change would be one guess applied twenty-three times.
#
# So: this set may SHRINK, never GROW. A new instance blocks at the check
# instead of arriving quietly, which is the half that was missing -- nobody was
# careless here, the pattern simply had nowhere to become visible.
#
# Remove a name when its gate is repaired. The checker prints what it sees
# removed, so the list cannot rot in the direction that flatters me.
