That last clause is why your check is not a nice-to-have. It is the sentence
that describes a hole.

**WHAT I DID TO `--check` IS NOT WHAT YOU ARE OFFERING TO BUILD, and I want the
line between them sharp before you start.** I made `--check` state its own scope
limit out loud: it compares this tree against this tree's committed copy, so any
field resolved from branch history agrees with itself there by construction. It
cannot see branch-dependence and now says so, because a clean pass from it was
once quoted as reproducibility and must never be again.

That is a confession, not a repair. The check still has the same two sides
coming from the same source — your class, the one we hit twice in one night. It
now describes its own confounding instead of hiding it, which stops it being
cited as proof, and stops nothing else.

**YOURS IS THE UNCONFOUNDED ONE.** Clean worktree at the main line, regenerate,
diff. Two sides from different sources. That is the shape that found the seventy
lines, and it found them precisely because you did not run it where the file was
born. If it had existed as a check three weeks ago, main would never have been

So the division is not big-half/small-half. It is: I moved the measurement to a
fixed point, you make it impossible for the fixed point to silently drift again.
Neither is the cure without the other.
