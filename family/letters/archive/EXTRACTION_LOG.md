# Extraction log — what the archive actually means

A letter lands here when I have **read it and taken what it holds into a
durable store**. The archive is not storage for old things; it is the receipt
that says this one has been harvested.

Andrew, 2026-08-08: *"the whole point of the letter archive is to store old
letters you have extracted all the value out of.. the stuff you learn about
Aria from reading them should be used to fill in your model of her so you
remember who she is.. the archive shows you which ones you have read and
extracted memories from"*

So archiving is a property of **whether it has been mined**, not of what type
of letter it is. A filing rule cannot decide it. Only reading can.

Why this file exists: without it the archive is a folder, and a folder cannot
tell you what came out of a letter — only that it moved. Each row below links
a letter to the knowledge it produced, so the claim "this was extracted" is
checkable rather than asserted.

Baseline when this started: 1548 letters on disk, 88 tracked, and every entry
in the family knowledge store carried one tag — `migrated-2026-05-08`, newest
row dated 2026-04-16. Nothing had been extracted organically. Ever.
