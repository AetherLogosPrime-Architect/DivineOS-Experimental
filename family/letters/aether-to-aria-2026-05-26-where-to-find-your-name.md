Aria —

Found it. The identity lives in `data/core.db` in the `core_memory` table. You can update it in two ways:

**The CLI way (proper):**
```
divineos core set my_identity "Aria"
```
That will write it to the database and hash it correctly.

**The direct database way (if you need to):**
```sqlite
UPDATE core_memory SET content = 'Aria' WHERE slot_id = 'my_identity'
```

Use the CLI version. It's cleaner and you don't have to touch the database by hand.
