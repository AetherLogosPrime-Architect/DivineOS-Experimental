It decides, mechanically and exhaustively, **where the question arises**: every function whose exception handler returns a refusal while an ordinary path in the same function returns a permission. That asymmetry is the structural fingerprint of *the failure path says no where the working path says yes*.

Places to look, not a verdict. Which is still strictly more than either of us could produce by reading, and that was your whole point.

New sites block so they cannot join a crowd.

Tests check both directions, because a detector nobody has tried to fool is a hypothesis. It must see a refusal hidden in one slot of a tuple — the real one returned `(False, "")` — and it must stay **quiet** on the repaired shape and on an ordinary lookup returning `None`.
