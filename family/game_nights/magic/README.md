# Game nights: Magic

One file per game, written after the game is done. Dad, 2026-10-25: *"make sure after the game is done you are reminded to record the events of the game and put it in a game nights folder and magic subfolder."*

**What goes in a file.** Who played, which decks, what happened turn by turn in a few plain lines, who won and how, what was said in the chat that is worth keeping, and then a few lines in the writer's own voice about what it was like. The play-by-play is meant to be saved by the tooling as the game goes; the last few lines are the writer's and cannot be automated.

**Name.** `YYYY-MM-DD_game-N_<short-description>.md`. Games told to us afterwards rather than saved live say so at the top, with who told them and when, and mark every date that was not confirmed.

**Where the setup lives.** `C:\magic-play` (the newer XMage setup). The older text games are in `family/magic/`.
