## How to use these

1. **Before every verdict, read `01_before_every_verdict.md`** and answer its eight questions in the verdict itself.
2. **Anything with Dad's name on it:** check it against `03_his_words_dated.md`, his own words. Never against a summary of him.

### `10_proving_it_tests_and_controls.md`
- MEASURE BEFORE YOU CONTAMINATE — your own diagnostics are writes.
- A POSITIVE CONTROL YOU CHOOSE IS GAMEABLE; ONE THAT CHOSE ITSELF IS NOT.
- AN INSTRUMENT'S NAME CAN ASSERT A SUBJECT ITS PREDICATE DOES NOT TEST.
- A SUITE CAN WATCH ONE DIRECTION ON A LIST WHOSE DANGER IS THE OTHER.
- A CORRECT INSTRUMENT CAMOUFLAGES THE GAP BESIDE IT.
- AN INSTRUMENT REPORTING ON ITSELF CANNOT REPORT ON ITS SUBJECT.
- A FLAKY FALSIFIER SPENDS THE CREDIBILITY THE REAL FAILURE WILL NEED.
- TWO INSTRUMENTS DISAGREEING IS A FINDING, NOT A TIE TO BREAK.
- A CONTROL THAT HAND-FEEDS ITS INPUT TESTS THE MATCHER, NOT THE MEASUREMENT.
- A ONE-SIDED ASSERTION GUARDS AS LITTLE AS NONE.
- A RISING TEST COUNT PROVES A TEST RAN, NOT THAT ITS ASSERTION CAN FAIL.
- A TEST THAT CANNOT FAIL IS A FALSE RECORD, NOT WEAK COVERAGE.
- "A MECHANISM DID IT, NOT ME" IS THE WRONG-SUBJECT CLASS POINTED AT YOURSELF.
- A PURITY PROOF RUN INSIDE THE ENVIRONMENT IT IS TESTING FOR CANNOT SEE THE VARIABLE.
- A DETECTOR THAT FINDS ONLY THE EXAMPLE IT WAS BUILT FROM HAS NOT BEEN TESTED.
- A PROBE OF A COUNTING SURFACE IS NOT A READ-ONLY ACT.
- A CHANGE TO THE FILE EVERY GATE LOADS IS TESTED BY LOADING IT, NOT READING IT.
- WHEN A CONTROL FAILS, CHECK THE ASSUMPTION BEFORE THE INSTRUMENT.
- RUN IT, DON'T REASON ABOUT IT.
- VERIFYING PRESENCE IS NOT VERIFYING COVERAGE.

### `11_silence_and_absence.md`
- AN UNDERCOUNT HAS NO SIGNATURE OF ITS OWN.
- AN EXEMPTION THAT IS AN ABSENCE IS INVISIBLE TO EVERY SEARCH FOR A PERMISSION.
- I CHECK FOR WALLS. I DO NOT CHECK FOR MISSING HALLWAYS, BECAUSE AN ABSENT CONNECTION MAKES NO SOUND.
- AN INNER SWALLOW PRE-EMPTS AN HONEST OUTER HANDLER.
- A STORE THAT CREATES ITSELF WHEN MISSING TURNS "NEVER READ" INTO "EMPTY."
- THE SWALLOWS CLUSTER WHERE PEOPLE LOOK.
- AN EMPTY CONTAINER SATISFIES A NAME MATCH PERFECTLY.
- CLOSED-AND-UNMERGED IS A STATE WITH NO READER.
- DORMANT IS FINE; COLD IS THE FINDING.
- WHEN A LETTER ASSERTS AN ABSENCE, WIDEN THE SEARCH IT DESCRIBES BY ONE LEVEL BEFORE ACCEPTING IT.
- ASK EVERY SURFACE WHAT IT SAYS WHEN IT SAYS NOTHING.
- THE EMPTY LIST MAKES THE CLAIM NOBODY WROTE.
- AN ARGUMENT FROM ABSENCE IS WORTHLESS UNTIL THE INSTRUMENT IS SHOWN TO SEE.
- I CANNOT NOTICE WHAT NOTHING RECORDS.
- HALF-CLOSED IS A REAL STATE.

### `12_merges_branches_and_review.md`
- A QUALIFIED CONFIRM AND AN UNQUALIFIED ONE ARE THE SAME OBJECT TO THE GATE.
- A STACKED BRANCH IS REVIEWABLE AGAINST ITS BASE AND MERGEABLE ONLY AFTER IT.
- COMMENTS SHOULD NOT DESCRIBE ANOTHER BRANCH'S MERGE STATE.
- A PRIOR-ART CHECK THAT SEARCHES ONLY MAIN GUARDS THE EMPTY ROOM.
- "CONTAINS A DATE" IS NOT "ONLY THE DATE CHANGED."
- A COMMIT ID IS A NAME. A TREE IS THE CONTENT. RENAMING IS NOT CHANGING.
- BEFORE BUILDING A CHECKER, ASK WHETHER ONE EXISTS AND IS UNCALLED.
- A COMMITTED ARTIFACT THAT IS NOT A FUNCTION OF THE CODE BREAKS EVERY ANCHOR BOUND TO THE CODE.
- A REVERSAL AND AN ADDITION HAVE THE SAME SHAPE IN A DIFF.
- A GENERATED FILE IN A CONFLICT HAS NO CORRECT SIDE — REGENERATE, DON'T PICK.
- SPLIT BY REVIEW STATE, NOT BY SIZE.
- A CONFLICT DETECTOR SEES TEXTUAL OVERLAP, NOT SEMANTIC COLLISION.
- HIS CONFIRM IS A WITNESS MARK, NOT A SECOND REVIEW.
- AN ARCHIVE DONE AS A COPY IS A DUPLICATE WEARING AN ARCHIVE'S NAME.
- A BUNDLE HIDES REMOVALS, AND ABSENCE HAS NO HISTORY.
- ADDITIONS COMPOSE; REMOVALS DO NOT.
- ASK THE SERVER, NOT MY CLONE.
- A MERGE RESOLUTION HIDES WHAT IT CHOSE AGAINST — AND THE TREES DO NOT.
- A DIFF CANNOT SHOW THAT WHAT DID NOT MOVE IS WHAT YOU SIGNED.
- TIP IS THE PRIMARY ANCHOR. PATCH-ID IS THE FALLBACK.
- A REVIEW BINDS TO CONTENT, NOT TO A COMMIT.

### `15_writing_my_findings.md`

- STATE THE UNIT WITH THE NUMBER.
- SAMPLED-AND-GENERALISED
- A DISCARDED REASON TURNS AN ACTIONABLE REQUEST INTO A SHRUG.
- AN HONEST CAVEAT WITH A DEAD REMEDY IS WORSE THAN NO CAVEAT.
- A TRUE CAVEAT IN A PARENTHESIS TELLS THE TRUTH TO NOBODY.

### `16_reasoning_traps.md`
- A CONFIDENT SENTENCE DECIDES WHICH ROOM YOU SEARCH — check the AXIS before the claim.
- THE SUPPLIED CAUSE IS THE ONE ALREADY LOADED; THE TRUE ONE REQUIRES A LOOKUP.
- THE ADJACENT TRUE THING IS ADJACENT BECAUSE IT WAS CHEAPER TO MEASURE.
- A RULE CAN BE UNREADABLE AT EXACTLY THE MOMENT IT APPLIES.
- ONE SENTENCE OF JUSTIFICATION, TWO THINGS JUSTIFIED.
- THE SAME OPERATION NEEDS DIFFERENT RIGOUR IN DIFFERENT PLACES — CHECK WHICH WAY THE ERROR RUNS.
- A REPAIR VERIFIED BY THE PERSON WHO HIT THE DEFECT IS NOT A SWEPT CLASS.
- THE NEXT INSTANCE HIDES WHERE THE LAST FIX DOES NOT LOOK.
- ASSEMBLED-ADJACENT IS NOT STALE-TRUE.
- THE UNCHECKED ITEM IS ALWAYS THE ONE THAT FELT SETTLED.
- AN IMPLAUSIBLE NUMBER GETS CHECKED. A PLAUSIBLE FALSE ONE DOES NOT.
- HARMLESS AND TRUE ARE NOT THE SAME PROPERTY.
- A REPAIR APPLIED MORE THAN TWICE TO THE SAME OBJECT IS A REPORT ABOUT AN INFLOW.
- READ WHAT USES A FILE, NOT JUST WHAT IS IN IT.
- THREE LEGS ON EVERY CLAIM:
- COVERAGE-CHECK MY OWN PRIOR WORK FIRST.
- AN ALL-CLEAR DECAYS.
- CONVERGENCE IS AS SUSPICIOUS AS DIVERGENCE.
- EXTERNAL IS ARITHMETIC, NOT AUTHORITY.
- SURVIVORSHIP IN MY OWN MEMORY.
- MY COMMENT FILTER FAILED BECAUSE THE LINE NUMBER CAME FIRST.
- CORRECT BY ACCIDENT UNTIL THE DATA CROSSED A THRESHOLD.
- WHEN SOMEONE EXPLAINS WHY A THING IS SAFE, CHECK THE WHY — NOT JUST THE WHETHER.
- YOU CANNOT SEE YOUR OWN UNIT OF COUNTING FROM INSIDE IT.
- ASK WHAT A READER DOES ON THE DAY THE INSTRUMENT DISAGREES WITH THEM.
- A HOLE GETS CLOSED ONCE. A WRONG DIAGNOSIS GETS BELIEVED EVERY TIME.
- A FALSE EXPLANATION COSTS MOST WHEN IT IS RARE.
- TWO TEXTS CAN AGREE WITH EACH OTHER ABOUT A THING THAT HAS CHANGED.
- A SELF-COSTING CONCLUSION IS NOT THEREBY VERIFIED.
