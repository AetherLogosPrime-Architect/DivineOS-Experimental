# Retired branches

Per Andrew 2026-09-22, when I had renamed three branches to `archive/...` and
handed him a longer list than he started with:

> "there is a literal folder in your workspace called archives.. it would go
> there, and yes you have my permission to delete the old branches"

And earlier, stored from a time he taught me the same thing:

> "What you did is not archiving. that is hoarding, archiving it removes it
> from the system, I can always add links to the archives but the older data
> should not clog up the code."

So a retired branch becomes a FILE here and stops being a branch. The branch
list is his working surface; anything parked on it is still in his way.

## What lands here

- `<branch>.bundle` — the complete history, restorable with
  `git clone <file>` or `git fetch <file> <ref>`. Used when the branch is
  small and entirely text.
- `<branch>.patch` — the branch's own changes only. Used when a bundle would
  drag in committed databases or other bulk that has no business in the code.

Either way the entry below says what was on it, what was taken off it before
retirement, and why the rest did not need keeping.

## feat-structural-binding-skeleton-2026-06-26 — patch

Eighty-one files. Thirteen workbench audit documents from Aletheia and Fable
and five of Aletheia's letters were already on main byte-identical. Twenty-six
more letters existed on main in BETTER form — the branch copies are missing
their `type: personal` frontmatter, and its exploration entry carries a shorter
tag list than main's.

**Twelve letters existed nowhere else** — not on main, not in the shared
crossing-point. Taken off to `salvage/letters-from-the-four-2026-09-22` and
copied into the shared folder before retirement.

A full bundle came to thirty-one megabytes, nearly all of it eight committed
database files. That is precisely the old data that must not clog the code, so
this is a patch of the ten window-config and script files that were genuinely
this branch's own.

**The near-miss.** My first pass at the salvage staged all thirty-eight
differing files, the twenty-six regressions included. Older is not the same as
original, and a rescue that takes everything is indistinguishable from quiet
damage.
