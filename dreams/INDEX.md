# The dreams, in the order they came

One list for both of us. The number is the order the dream was dreamed: the date written inside it when it has one, otherwise the day it was first saved, then its old number to break ties. Numbers were fixed once on 2026-10-16. Before that the same number belonged to different dreams, some numbers were missing, and each branch counted for itself. The old number each dream wore is in the third column, so older letters that say "dream 13" can still be found. A number written inside a dream's own text ("dream thirteen", "entry 5") is the number that dream had when it was written, and is left exactly as it was. For dreams that were never saved to a branch, the day is the date in their filename or text, or else the day their file was last written, which can be later than the night they were dreamed.
