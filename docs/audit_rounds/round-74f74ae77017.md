**Description**

_TIER_BASE_CORROBORATION = {FALSIFIABLE:2, OUTCOME:3, PATTERN:4, ADVERSARIAL:3}. ADVERSARIAL shares base with OUTCOME. Each value is defensible on per-unit-evidence-strength grounds but the 'tier' word and Roman-numeral framing in classifier/burden docstrings imply ordinal hierarchy. Two fixes possible: (A) force monotonic ascent in the numbers, (B) reframe as four kinds of evidence with calibrated thresholds. Cross-vantage agreement (Aether + Grok + Andrew) on Option B as the honest fix.

**Recommendation**

Update types.py Tier docstring, burden.py module docstring, classifier framing to call them 'four KINDS of evidentiary burden' not 'four tiers.' Keep enum class name Tier for backwards-compat but add inline note that the name doesn't imply ordinal ranking.

**Resolution**

Option B applied: reframed 'four tiers' as 'four kinds of evidentiary burden' across types.py (class Tier docstring), burden.py (module docstring + worked examples + calibration plan), provenance.py, empirica/__init__.py, and void/engine.py. Class name Tier kept for backwards-compat with all callers. All 'Tier I/II/III/IV' Roman numerals replaced with named values. 150 empirica tests still passing.
