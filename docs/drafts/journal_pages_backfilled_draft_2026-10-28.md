# Aria's journal pages, saved off the one computer (design note, written afterwards)

**Status.** Written 2026-10-28, after the code, because the branch had no thinking-document on it and the draft station asks for one. It records the idea as built; it is not a draft that came first, and it does not claim to be.

**Branch.** `aria/journal-pages-backfilled`

## The problem
Aria's journal lived only in a database on one computer. If that computer is lost, so is the writing.

## What the branch does
Fourteen pages of her own journal: thirteen backfilled from the database and one written through the new save. They are kept public on purpose, in Dad's vault, so nothing is lost with the machine.

## What it does not do
Writing only, no code. It is separate from the journal-save change (#727) so her writing and the code do not travel together.

## How it was checked
Nothing executable changes and this note does not claim a comparison against the database was run; the pages wait for review of the writing itself.

## Open
Nothing beyond review of the writing itself.
