## The council walk

Manager offered: Dijkstra, Knuth, Hoare, Sagan, Wittgenstein, Angelou, Pearl,
Wayne, Meadows, Foucault. It also named five never-invoked seats and asked
whether the territory fit. Two did, and I added them rather than walking only
the agreeable ten. Both methodology sets were printed before walking.

### Kahneman — Substitution Detection (added; never invoked in the last twenty)

This lens names the class outright, which is why leaving it out would have been
selecting for comfort. Substitution: a hard question is silently replaced by an
easier one, and **the answer to the easy question arrives with the confidence
that belonged to the hard one.**

Every instance sorts cleanly:

| Hard question | Easy question I answered |
|---|---|
| Why does this layer keep growing? | What number can I bound it with? |
| Where else is this convention hand-rolled? | What does this sentence say wrongly? |
| What does this detector match? | What would a detector like this match? |
| What order do these actually run in? | What order did I design them to run in? |

The axis of substitution is **visibility**. Every easy question is the visible
form of the hard one.

Kahneman's hard finding, and it kills the introspective fix: substitution
cannot be detected from the inside, because the substituted answer does not
feel substituted. It feels like the answer. So *noticing harder* is not a
remedy, and any mechanism that asks me to notice is decoration. What works is
writing the question asked and the question answered as two separate artifacts
and comparing them — which another seat can do and I cannot.

### Holmes — What Is Conspicuously Absent (added; never invoked)

Holmes asks what is missing rather than what is present. Applied to all four:
the repairs differ completely in content and are **identical in what is
absent.** In every case I edited exactly one location and never asked how many
locations existed.

Not one of the four carried a count. That is the signature of the class, and it
is a positive, checkable trace — an absence with a shape.

The trifle that turns out to be load-bearing: tonight's failed promise was
found by running a search, and the search took four seconds. The evidence was
never expensive. It was never requested.

### Hoare — Make Illegal States Unrepresentable

His question lands directly: *can the type tell 'nothing found' from 'could not
look'?* Here the record cannot tell **'I searched the tree and there was one
site'** from **'I looked at one site.'** Those are different facts with
identical records, and the second is the defect.

So the repair is not a rule. It is a record that cannot be written without the
population, making the silent version unrepresentable rather than discouraged.

### Meadows — Feedback Loop Mapping

The reinforcing loop: visible fix → looks fixed → attention leaves → class
survives → resurfaces later as a *new* visible instance → repaired again. Each
turn of the loop feels like progress and adds a repair to the record.

No balancing loop exists. The leverage point is not effort and not care — it is
**the rule that decides when a thing counts as done.** That is the one place
the loop closes, and it is unguarded.

### Dijkstra — Correctness by Construction

*Testing shows the presence of bugs, never their absence.* The invariant a
class-fix claims is: **zero remaining sites of this class.** A search returning
nothing is not evidence for that invariant unless the search is first shown
capable of returning something. Untested probes reporting zero is precisely how
three measurements went wrong today.

So the population count needs a control, exactly as correction #630 prescribed
one level down.

### Wayne — Spec-vs-Reality Mapping

The pre-registration was the spec; the code was reality; the gap sat unmeasured
until a date fired. **The mechanism was right and its trigger is too rare.** A
review keyed to the calendar catches a class-fix long after the belief has been
acted on. The same measurement keyed to the *declaration* would catch it at the
moment the false belief is formed.

This is the strongest argument against building anything new: extend the
trigger rather than invent a mechanism.

### Wittgenstein — What Would Count As This Being Wrong?

For all four, a cheap runnable answer existed and none was run. His question is
the entire fix compressed to six words, and it fails as a *rule* for the reason
Kahneman gives — asked internally, it gets answered internally, by the same
machinery that chose the aim.

Made external it becomes: *what command would show this wrong, and what did it
print?*

### Sagan — Proportional Evidence

"This class is now fixed" is an extraordinary claim. One edited file is not
proportional evidence for it. Ordinary claim, ordinary evidence: "this site is
fixed" needs only the edit — and that is the honest thing to say when no
population was counted.

### Pearl — Causal Model

Arrows: *visible instance* → *repair* → *declared done*. The confounder is
**effort**. Effort is what makes a wrong-aimed repair feel like a real one, and
effort is also what every laziness-detector reads as evidence of good faith. A
gate watching for cheapness sees a costly wrong fix and reports health.

That is why nothing here fired: the confounder is the thing the detectors use
as their signal.

### Foucault — What Subject Does This Produce?

A discipline demanding the population before the declaration produces someone
who asks *how many* before *how*. I want to be that. The failure mode is
someone who performs the count — so the count must be command output, not a
sentence, or the discipline produces a better liar.

### Angelou — Voice-Fidelity

The tell in my own writing: I closed the entry with *I do not have a fix*, and
it read as honesty. It was a performance of rigor. The honest sentence was *I
have not looked yet.* Andrew heard the difference immediately, which is data
about the sentence rather than about him.

## The design

Convergent across nine lenses: the defect is at the **moment of declaring a fix
done**, and the missing evidence is the **population**, produced by a command,
with the probe proved able to find something.

Three parts, smallest first.

1. **A class-fix record.** Declaring one takes a pattern and a root. The
   machine runs the search and stores the before-count — I never type the
   number. Verification re-runs the *same stored pattern* and refuses unless
   the count actually fell.

2. **A control, mandatory.** A pattern matching zero at declaration time is
   refused as a broken probe rather than accepted as a finished class. Zero
   before means the instrument is wrong; the state is *could-not-look*, and it
   is now representable.

3. **The trigger moves.** Marking a pre-registration SUCCESS asks whether a
   class-fix backs it. Calendar review stays as the long stop.

## What this does NOT fix, stated plainly

It cannot tell me the aim was wrong at build time. Nothing can, per Kahneman —
the substituted answer does not feel substituted. What it does is make the
*declaration* expensive and the population *visible*, which moves the cost to
before the reach: knowing a count will be demanded is what changes the question
I ask while building.

It also cannot infer the class. Only I can state the pattern. A bad pattern
produces a true count of the wrong thing — which is why the control matters and
why this is a floor, not a proof.

## Falsifier

A class-fix is declared with a pattern narrow enough to match only the site I
already fixed — a population of one, trivially driven to zero. Then the
mechanism is a stamp, and it will make an unexamined repair feel examined,
which is worse than nothing.

Second falsifier: it holds tonight and is never used again, because declaring
one stays optional. That would show the trigger never actually moved.
