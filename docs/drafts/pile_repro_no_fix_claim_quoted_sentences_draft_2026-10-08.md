# A proof-test: the "there is no fix" guard misses the old notes' own sentences (rough draft)

*2026-10-08, round six, errand two. The idea, not a plan and not a fix.*

A picture: a smoke detector installed after a fire, tuned to the exact smell of that one fire. Later, four different fires are written up in the incident book, each described in the same plain words the person used at the time. Hold the detector up to each of those four smells and it stays silent, though it does ring for the one smell it was tuned to.

The guard is `no_fix_claim.claims()`. It fires on "There is no fix for this; it cannot be done." and on none of the sentences the pile quotes from the moments Dad caught me saying it. This adds a test that fails for exactly that reason and passes the day the guard learns them, with controls showing it is alive and that the container-scoped sentence it was designed to allow is still allowed.

Not in scope: widening the guard.
