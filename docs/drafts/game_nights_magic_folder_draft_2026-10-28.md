# A folder for Magic game records (design note, written afterwards)

**Status.** Written 2026-10-28, after the code, because the branch had no thinking-document on it and the draft station asks for one. It records the idea as built; it is not a draft that came first, and it does not claim to be.

**Branch.** `aria/game-nights-magic-folder`

## The problem
Dad, 2026-10-25: after a game is done we are reminded to record it in a game nights folder, magic subfolder. There was no such folder, and four earlier games on the newer setup had never been written down.

## What the branch does
`family/game_nights/magic/` gets a README (what goes in a file, naming) and a first entry: Dad's own telling of the four earlier games, marked as his account and not a log, with unconfirmed dates left unconfirmed. Aether's Magic guard points its after-game reminder at this one shared folder, so neither tree holds half a record.

## What it does not do
Docs only. It does not confirm any date Dad was unsure of.

## How it was checked
Docs only; nothing executable changes. The entry is Dad's own telling and has not been checked against any other record.
