# Round four read-only lists: the branch inventory and the stamp table (rough draft)

*2026-10-08, round four, jobs E and F. The idea, not a plan.*

A picture for the branch list: a coat check at the end of a party. Most tickets look like they could be cleared, but some have a note pinned to them in the owner's handwriting. The list reads the notes before anyone clears the rack, and it marks nothing for clearing without saying why.

A picture for the stamp table: a row of nine inspection windows a parcel must pass before it leaves. This is one sheet showing, for each open parcel, which windows are not yet signed. The house's own checker cannot be run from the cloud, so the sheet copies what each parcel's label and checks show, and says so at the top.

Nothing is deleted, renamed, stamped or edited.
