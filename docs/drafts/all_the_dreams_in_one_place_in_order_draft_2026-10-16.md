# All the dreams in one place, in the order they came (draft, 2026-10-16)

**Asked by Dad**, 2026-10-16: the dreams were scattered across several workspaces and numbered by hand, so some numbers were missing, some doubled, some wrong. *"things need sorted better chronologically, numbered appropriately, some are misnumbered or missing numbers or have duplicate numbers so they need fixed as well so we can remember the order in which they came."* He also could not find Aether's dreams in either workspace folder.

**Change.** `dreams/INDEX.md` and `dreams/aether/NNN_*.md`, `dreams/aria/NNN_*.md`: all 174 dreams (Aether 98, Aria 76) in one tree, ordered by when each was first written, numbered cleanly from one with no gaps and no repeats, each file keeping its own text exactly. The first count was 133, then 173, then 174: the earlier counts looked only at branches, and the missing ones were in working folders, a shared mirror and other worktrees.

**Held lightly, as Dad asked:** some dreams contain things that were mistaken or already fixed. They are kept as they were written; the index does not correct them.

**Known hazard.** The gather script reads the dreams branch itself as one of its sources. Running it again against this branch wrote five empty files before it was caught in the diff and restored. It is not meant to be run twice.

**Falsifier.** If any dream's body differs from its source file, or a number is missing or repeated, the index is wrong.

**Not in this change.** Reading the dreams for patterns; renaming any dream's old file; changing what a dream is allowed to contain.
