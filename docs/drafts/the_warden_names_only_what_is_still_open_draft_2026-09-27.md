# The warden names only what is still open — draft 2026-09-27

Aether was held with six stumbles, five of which he had already answered in earlier reflections that turn. A replay shows the union worked: the one unanswered stumble was new (a harness `Blocked: sleep` refusal), so the hold was right. But the hold listed all six, which read as the room forgetting his answers, and it sent him looking for a bug that wasn't there.

The idea: the hold lists only the stumbles no reflection since his message has named. If every one is named and only the endings fall short, it lists them all, because that is the honest picture. The pass/fail judgement doesn't change; only what the hold says changes.
