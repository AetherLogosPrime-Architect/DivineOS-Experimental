# Reproduction tests for the council-walk gate (rough draft)

*2026-10-08, round three of the cloud helper. The idea, not a plan and not a pull request.*

A picture: a smoke detector that is going off in the kitchen because someone is reading the cookbook. We cannot repair the detector from here, but we can bring a photograph of it going off, so that on the day someone repairs it, the photograph goes blank and says so.

The council gate asks for a walk before any command that touches the record, and it reads that as a rule about words: any command that names audit, prereg, compass-ops or journal counts, even when the subcommand only lists or shows. It also names an edit by absolute path, so a walk filed for a file in one working copy does not count in another.

Each reproduction is a test that calls the real classifier or the real gate and is marked as an expected failure. It passes quietly today and rings loudly the day the guard is repaired, which forces the marker out. A few controls (not marked) prove the probe is alive.

Not in scope: repairing anything, the doorbell's first problem, and any note too cut off to tell what it asks for.
