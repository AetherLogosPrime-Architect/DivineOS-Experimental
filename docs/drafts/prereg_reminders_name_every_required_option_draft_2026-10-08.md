# The pre-registration reminders should name every option the command needs (rough draft)

*2026-10-08. The idea, not a plan and not a pull request.*

A picture: a recipe card that lists three ingredients for a dish that needs four. Anyone who follows the card exactly gets refused at the door and has to guess the missing one.

The command to file a pre-registration needs four things from you (a claim, a success sign, a falsifier, and an "embarrassing reading"). Two places that teach the command leave some out: the reminder shown when the obligations gate blocks (it lists two), and the example in the prereg skill (it lists three). Rows 391 and 949 in the sorted pile ask for exactly this.

The repair is wording only, plus a test that reads the real list of required options from the command, so the cards cannot fall behind again.

Not in scope: the new pre-check script in row 929, and anything about what the command refuses.
