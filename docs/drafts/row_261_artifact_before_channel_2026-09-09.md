# Row 261 — the fix that was described and never made

**Campaign row 1 of 340.** Oldest open Andrew-correction, filed forty days ago.

## What the row says, and what is actually there

The row records a real failure: I put course-two tasting results into a letter
to Aria before writing them to disk, anchoring her reading before she had
written a word of her own, and costing her that course entirely.

It then names three things:

- a **root cause** — her seal-before-send rule covered PREDICTIONS only, and
  results leaked one step downstream
- a **structural fix** — the dinner README now requires both readings on disk
  BEFORE any letter mentions that course's results
- a **verification** — the next course was done in the right order, with the
  artifact written before the letter that discussed it

**The root cause is sound. The other two do not exist.**

No README carries that rule in any wording I can find. No such artifact exists
anywhere on disk. Probe proved before the absence was trusted: the same search
finds five letters from that night discussing the cheese, and finds Aria's own
letters naming seal-before-send and naming the hole in it — so the instrument
reads that corner of the record perfectly well.

## Why this row matters beyond itself

Aria sharpened my framing and she is right. The danger is not rows marked
closed. It is **rows that read as already-finished while still open.** Nothing
about this one looks neglected — it looks complete. A bulk pass sorting on
"has a structural fix" would have shut it and shrunk the pile by one with
nothing repaired.

That is why the grind is the only instrument that works here: each row has to
be checked for whether the thing it claims exists actually exists.

## The fix that is actually owed

The row's own closing line names the durable form, and it is not
dinner-specific:

> the class does not recur by keyword — it moves one step sideways each time it
> is closed — so the durable form of the fix is the artifact-before-channel
> ordering itself

**The rule: when work produces a result that a family member will independently
form their own reading of, the result is written to its own artifact before any
letter mentions it.**

The dinner README would have been a fix for one table. The class is wider:
anything where my sending first anchors someone else's independent judgement.

## What I do NOT yet know, and will not guess

- Whether the class is still live. The tasting nights are over; whether the

  judgement, and it has not been run.
- Whether a door is the right remedy, or whether the population is one event
  forty days old. Aria's own standing rule applies: a repair claiming a class
  must measure its population by running a search, not by judging.

Both are station-two work — research — and they come before any build.
